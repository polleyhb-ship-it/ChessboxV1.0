# Chess app with source code
This is a lightweight windows chess app, easy to use and fairly strong with a basic openings repertoire. Code (C/C++) is included in the source directory, and can compile on Windows or Linux with FLTK installed.
<img width="624" height="498" alt="chessBoxFullBoard1" src="https://github.com/user-attachments/assets/8a1e4811-b3ea-4331-a635-b31d3365d1b2" />

The chess engine uses the Minimax method with alpha-beta pruning, and Zobrist hashing.
The zip file in the **release** contains a document on how it works
